# create-anthony-app

Genera proyectos base listos para usar desde la terminal.

## Uso

```bash
npx github:Anthonyzc05/create-anthony-app react-firebase mi-proyecto
```

El comando copia la plantilla, te pide los datos de tu proyecto de Firebase, crea el archivo `.env` y te muestra los siguientes pasos.

## Plantillas

| Plantilla | Incluye |
|---|---|
| `react-firebase` | React + Vite, login con correo y Google, registro, rutas protegidas, manejo de errores |

## Requisitos

- Node.js 18 o superior
- Un proyecto en [Firebase](https://console.firebase.google.com) con Authentication activado
